- **기술 스택**: NestJS, PostgreSQL, Docker, GCS,

- **맡은 역할**:
    - Backend

## 2. 프로젝트 배경

본 프로젝트는 사용자가 기록하는 노트를 로컬 파일 관리와 클라우드 동기화를 결합하여 노트를 작성하면서 AI가 내용을 분석하여 깊이 있는 질문과 지식을 제안합니다.

이를 활용하여 사용자가 노트를 공개하면, 해당 노트는 다른 사용자가 참고하거나 열람될 수 있어 지식 간의 유기적인 연결을 가능하게 해주는 프로젝트입니다.

단순한 지식 정보를 적는 것을 넘어 작성한 노트를 기반으로 지식의 빈틈을 채우는 데 도움을 주는 AI의 피드백으로 생선성 향상을 위한 요소가 됩니다.

기존 노트 앱들이 정보를 기록하는 데 초점을 두었다면, NewLearnNote는 정보를 기록하고 활용하는 데 집중했습니다. 정보의 양이 많아지는 현대사회에서 다른 사람의 노하우를 배우고 어려움을 해결하고자 정보 과부하와 지식 공유의 단절 문제를 해소하고 성장시키기 위해 탄생했습니다.

## 3. 프로젝트 주요 기능

### 3-1. AI 기반의 능동적 학습 코치:

    - **콘텐츠 기반 질의**: 사용자가 노트를 작성하면 Gemini 기반의 AI가 내용을 분석하여 깊이 있는 질문을 던지거나, 관련 지식을 즉시 제안합니다.
    - **문서 수정 및 보조**: 사용자 요청 시 채팅 형태로 문서 내용을 요약하거나, 문맥에 맞는 보충 내용을 제안하여 글쓰기를 돕습니다.

### 3-2. 집단지성 네트워크 및 상호 참조:

    - 사용자가 노트를 **공개(Publish)** 하면, 해당 노트는 네트워크를 통해 다른 사용자에게 검색되고 열람됩니다.
    - 다른 사용자의 공개 노트를 자신의 노트에서 **직접 참조**할 수 있으며, 이는 지식 간의 유기적인 연결을 가능하게 합니다.

### 3-3. 크로스 플랫폼 및 로컬 관리:

    - **데스크톱 앱(Electron.js)** 을 통해 로컬 파일 시스템을 직접 관리하여, **Obsidian**과 같은 강력한 파일 관리 경험을 제공합니다.
    - 클라우드 동기화 기능을 통해 여러 기기 간 데이터 일관성을 유지하며, **유료 구독 시 클라우드 저장 용량을 제공**하여 서비스 확장성을 확보합니다.

## 4. 현재 구현 상태

본 프로젝트의 최종 목표는 인공지능 도입을 통해 사용자의 빈틈을 채우는 데 도와주고, 다른 사용자의 노트를 참조하고 인용하여 네트워크를 구축하여 AI 집단 네트워크 노트를 만드는게 최종 목표이다. 현재 인공지능 도입과 결제 로직을 구현중에 있고, 다른 노트들을 연결하는 네트워크 구조를 현재 구현하고 있습니다.
